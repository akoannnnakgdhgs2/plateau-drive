埼玉 PLATEAU ドライブ試作 v2
===============================

スマートフォンのブラウザで試すためのWebプロトタイプです。

改善点
- PLATEAU配信サービスのデータカタログAPIを呼び出し、都市別3D Tilesを探して表示する処理を追加
- 鴻巣市・さいたま市・熊谷市の切り替えUI
- モバイル向けタッチ操作、ギア、カメラの簡易デモ

注意
- 実際に都市データが読み込めるかは、配信APIのレスポンス、CORS、通信環境、都市のデータ形式に依存します。
- 車は地理座標上を動く簡易マーカーです。道路の上を正確に走る機能はまだありません。
- 自動ブレーキのボタンは設定UIのみで、建物との衝突検知はまだ接続されていません。
- 予測線・360度カメラはUIの試作で、実車同様のカメラ合成ではありません。
- 実際の運転ゲームにするには、PLATEAU道路モデルの取得、道路中心線へのスナップ、車両の衝突判定、カメラ追従の改善が必要です。

起動
- index.htmlをブラウザで直接開くと、外部モジュール・通信制限で動かない場合があります。
- 静的WebホスティングにアップロードしてHTTPSで開く方法を推奨します。
- 外部のCesiumJSとPLATEAU配信サービスを利用するため、インターネット接続が必要です。
